# AI & llms.txt

Ack publishes a focused, machine-readable product summary at [`/ack/llms.txt`](/ack/llms.txt). It mirrors the repository root [`llms.txt`](https://github.com/btwld/ack/blob/main/llms.txt) so tools can discover Ack's packages, runtime API, code-generation workflows, and migration notes without parsing HTML.

The canonical docs.page site also generates a page index and a full documentation export automatically:

- [`docs.page/btwld/ack/llms.txt`](https://docs.page/btwld/ack/llms.txt) lists every documentation page with its title, summary, and canonical URL.
- [`docs.page/btwld/ack/llms-full.txt`](https://docs.page/btwld/ack/llms-full.txt) bundles the full MDX source for one-shot ingestion.
